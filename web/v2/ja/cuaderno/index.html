ノート

Solanaトークンを読んで、このブラウザでカードを保存します。 ウォレットを接続しない、署名しない、送信しない。

ネットワークを選択します。 このページが開くと、ネットワークはSolanaになります。 Baseでは、読み込みも読み取り専用です。ウォレットや署名はありません。 各カードは、ネットワークとアドレスを格納します。

このブラウザでのみ書き込みが保存されます。 キー、シード phrases、または個人データを記述しないでください。 削除を解除します。 チェーンを 読むには、ブラウザは パブリック Solana サービス (デフォルトでは solana-rpc.publicnode.com 、または選択したもの) を問い合わせ、アドレスと IP を受信します。

当サイトでは、サーバー上で閲覧したアドレスは保存されません。 ライブを閲覧するには、Solana パブリックノード solana-rpc.publicnode.com と api.mainnet-beta.solana.com に送信され、IP も表示されます。 「今すぐ市場データを読み込み」を押すと、お使いのブラウザはDEX Screenerに接続し、IPアドレスと表示アドレスも確認できます。 「このルックアップを保存」を押すと、このブラウザのノートブックに保存され、デバイスに保存され、いつでも削除できます。 市場データは保存されません。

オーディションや勧告ではありません。 記載された時点では、パブリックチェーンデータが表示されます。トークンが良い、安全、または良い購入かどうかは言うまでもありません。

保存したカードは、時間の状態を把握し、これを変更することがあります。 新しいクエリは、以前のクエリを現在の読み込みに変えません。

公開リーダーの変更

api.mainnet-beta.solana.com と solana-rpc.publicnode.com の2つのリーダーのみがあります。 別の読者を選択した場合、そのサービスは、あなたの質問とあなたのIPを受信します。 ORVUPI はレビューしません。
