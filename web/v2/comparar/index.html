Ejemplo educativo. No es una comparación de calidad, ni una recomendación, ni un aval. ORVUPI no tiene relación con ningún token de este ejemplo.Educational example. It is not a quality comparison, a recommendation, or an endorsement. ORVUPI has no relationship with any token in this example.

Ejemplo hipotético, no leído de la cadena. Fecha del ejemplo: 2026-10-10.Hypothetical example, not read from the chain. Example date: 2026-10-10.

Una curva abierta junta dos cantidades virtuales: la de la moneda del token y la de SOL. Si una se mueve, la otra se mueve en el sentido contrario. Esta página no calcula ese movimiento.An open curve pairs two virtual amounts: the token currency and SOL. If one moves, the other moves the other way. This page does not calculate that move.

Cuando la curva está completa, ese paso ya no cabe. Si no hay curva, no hay cantidades que mostrar. Aquí las cantidades son redondas y de ejemplo.When the curve is complete, that step no longer fits.
