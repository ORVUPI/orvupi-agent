Learn

A glossary and three guides for reading any Solana token. It is static text: this page does not call the network.

English: pending human review. If a sentence does not match, the Spanish version prevails.

It is not an audit or a recommendation. It shows how to read public data; it does not say whether a token is good, safe, or a good purchase.

The only example that uses a real token is the USDC address on Solana: EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v

Glossary

Mint address

It is the account that identifies that token on Solana. The name and the symbol are separate text: two tokens can share a name and still be different addresses.

Example. The USDC address on Solana is EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v. Another address, even if the name looks similar, is not this one.

It does not let you conclude: it does not name a person, and it does not say that any action with the token is advisable.

Curated registry

A local list Verify compares with the mint, name, symbol, image, and some links. In the examples it includes USDC. ORVUPI is not on it. A mint that is not on the list is not necessarily fake.

Example. USDT, on the 2026-10-16 card, is not in the registry. The card itself says that does not mean it is false or a copy.

It does not let you conclude: being in the registry is not an audit. Being absent also does not say that someone else’s token is good or bad.

Mint authority

Permission to increase the supply of that mint. Revoked, when the field is verified, means that permission is recorded as empty in that reading. Active means it is still assigned to an address.

Example. In the 2026-10-16 batch, the three “USD Coin” copies have it revoked. USDC and USDT have it active.

It does not let you conclude: a revoked mint authority does not stop the price from falling, and it does not predict demand or liquidity. An unavailable field is not filled in as revoked.

Freeze authority

Permission to freeze accounts of that token. It is different from mint authority. Revoked removes it in that reading. Active leaves it assigned.

Example. In the same batch, the registry mint has it revoked and USDC has it active, assigned to an address the card shows.

It does not let you conclude: it is not a guarantee or proof of identity. The absence of this permission does not rule out other restrictions on the token.

Mutable metadata

If is_mutable is true, the name, the symbol, or the image can change later. “No” describes that account at that time.

Example. On 2026-10-16, the 5vJmAfBjsS6wEHcgQGNm69P3fbyPmUU1dVfE5j1rraVZ copy is recorded as not mutable in the sources read. USDC has is_mutable true in Metaplex.

It does not let you conclude: that they cannot be changed does not show legitimacy. That they can be changed is not, by itself, impersonation.

Unknown and unavailable

Unavailable means that call did not leave a usable fact. Unknown is what was not read. Neither one is a zero.

Example. If the reader returns HTTP 429 or the time runs out, the card stays partial and records the time. It does not invent a supply.

It does not let you conclude: it does not become a revoked authority, immutable metadata, or a zero amount.

Pump.fun curve

A derived account. If its program is the curve program, public fields are read. If there is no curve, those amounts are not filled in with zero.

Example. None of the 2026-10-16 cards is a Pump.fun curve: on USDC, USDT, and the copies, progress stays not applicable. On a token that is on the curve, progress is inferred from the real amount left.

It does not let you conclude: progress does not say what to do. This page does not simulate a swap.

Real curve amount

The real field of the curve account, in base units. It is different from the virtual amount.

Example. On the official card it is shown as an integer that was read, not as a balance this page treats as withdrawable.

It does not let you conclude: it is not an audit of funds. If the field is absent, a zero is not invented.

Virtual curve amount

The virtual field of the same account. It is used by the curve calculation and it is not the real amount.

Example. The official card shows the virtual amount and the real amount as different numbers.

It does not let you conclude: adding them does not create one available pool.

Possible impersonation

A Verify signal: the name, symbol, image, or a link matches the curated registry and the mint is a different one. The match does not attribute intent.

Example. Verify can show that signal on a dated card whose address is not the official one. For any other token, this library does not use that word.

It does not let you conclude: it is not a verdict. A similar name does not replace reading the address.

Account and person

An address stored on an account is a public field. It does not identify a person or a legal owner.

Example. The curve creator, when the card includes it, is still an address.

It does not let you conclude: this page does not turn an address into a person’s name. It does not ask for personal data.

‘Holder’ (industry term)

‘Holder’ (industry term): an account that holds tokens. It implies no rights and no investor community.

Example. An account that holds tokens is not, from that fact alone, a person.

It does not let you conclude: it implies no rights and no investor community.

Card

A dated reading of an address. It does not update itself and it is not an audit.

Example. The official card used here is dated 2026-10-09. A later query is another card.

It does not let you conclude: an old card is not the current state. It may have changed.

Census

A census would be the list of every account. These readings are not that: if a fact is missing, it is not filled in with a zero.

Example. The official card says which accounts it read and that this is not a census.

It does not let you conclude: not being a census does not turn the missing fact into a zero.

Fee

A fee rule set by a connector on a swap. This library does not calculate fees or swaps.

Example. The guides read public fields. They do not add a fee calculation.

It does not let you conclude: a fee does not identify the mint and is not a promised result.

Token-2022 extension

Extra data on a Token-2022 mint, after the base account. Classic SPL Token does not have them: the status stays not applicable.

Hypothetical example, not read from the chain: an extension can be named TransferFeeConfig or PermanentDelegate. If the type is not on the list, it is marked not supported and its effect is not invented.

It does not let you conclude: seeing an extension’s name does not say whether the token is safe or what that extension will do in a swap.

Guides

Identify a token

The name, the symbol, and the image are text and a file. The mint address is the account of that token.

For any token the order is the same: read the full address and do not replace it with the name, even if the name contains words such as official or community.

The only real token this guide states is USDC, and only by its address EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v. Any other address is not the USDC address. That does not say whether that other token is good or bad.

A card has a UTC time. Checking again creates another card. What could not be read stays unavailable.

Try it in Verify. The link opens Verify empty: it does not paste a third party’s address.

Read permissions

A permission is not a guarantee. Mint authority, if active, can increase the supply of that mint. If it is revoked and the field is verified, that specific permission is recorded as empty in that reading.

On a stablecoin, an active mint authority is common: the issuer adds units when money comes in. If a project promised a fixed supply, the same permission can create more. The reading does not say which of the two cases this is, and it does not accuse.

Freeze authority is a different permission. Revoked removes it in that reading. Active leaves it assigned to the address the card shows.

On Token-2022, extensions can appear after the base account. If the type is on the list, the name is shown. If it is not, it stays not supported. On a classic SPL mint, extensions do not apply.

A revoked mint authority does not stop the price from falling and does not predict demand or liquidity. A hypothetical example, not read from the chain: a token with mint authority revoked can still have no liquidity.

If a field is unavailable, it is not filled in as revoked or as immutable.

Try it in Verify

Understand the curve

The Pump.fun curve, when it exists, is a derived account. Virtual and real amounts are read separately, and so is whether complete is true or false.

The virtual amount is not the real amount. They are not added together as one withdrawable pool.

If the derived account is not owned by the curve program, the field stays not applicable. It is not filled in with zero.

Market cap is not the curve’s liquidity. This guide does not calculate market cap, fees, or a swap.

A hypothetical example, not read from the chain: a curve marked complete does not say what the price will do later.

Save the reading in the notebook if you want to compare it later. The saved card will show the time and that it may have changed.
