Curve reading

Paste any Solana mint. If there is a Pump.fun curve, you see the base currency and the curve state, as they are on chain. If there is no curve, the page says so.

Public data reading. It is not a quality comparison, a recommendation, or an endorsement. ORVUPI has no relationship with these tokens.

It is not an audit or a recommendation. It shows public chain data at the stated time; it does not say whether a token is good, safe, or a good purchase.

Writing an address does not endorse that token. It does not connect a wallet, it does not sign, and it does not send.

A pairing is not a collaboration or an endorsement.

The read uses https://solana-rpc.publicnode.com and https://api.mainnet-beta.solana.com, in that order. If the first one does not answer, it tries the next. Those services receive the address and the IP under their own terms. This page does not write the Notebook. The metadata link is shown as text and is not opened.
