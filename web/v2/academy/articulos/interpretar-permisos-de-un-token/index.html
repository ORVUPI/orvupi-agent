Interpretar los permisos de un token

AvanzadoActualizado 03-11-2026 2 min✓ Leído

Aspectos clave

  • La autoridad de emisión puede crear nuevas unidades del token.
  • La autoridad de congelación puede bloquear cuentas que tienen el token.
  • Un permiso activo no es una acusación: una moneda estable regulada los necesita.
  • Un permiso revocado no es una garantía: una copia puede tenerlos cerrados.

Dos permisos básicos

Cuando se crea un mint en Solana se pueden asignar dos autoridades:

  • Autoridad de emisión. La cuenta que puede crear más unidades. Si está activa, el suministro puede crecer.
  • Autoridad de congelación. La cuenta que puede bloquear las cuentas de token de otras personas para que no puedan moverlo.

Cada una puede estar activa (asignada a una dirección) o revocada (sin dueño, de forma permanente).

Leer en contexto

El mismo dato significa cosas distintas según el tipo de token:

  • En una moneda estable respaldada por un emisor, la emisión activa es la forma normal de crear unidades cuando alguien deposita dinero. La congelación puede servir para cumplir órdenes judiciales.
  • En un token que dice tener un suministro fijo, una emisión activa contradice esa promesa y merece una pregunta.

Ninguno de los dos casos dice si el proyecto es honesto. Tampoco lo dice un permiso cerrado: una copia que se hace pasar por otro token puede tener las dos autoridades revocadas y seguir siendo una copia.

Más allá de los dos permisos

El programa Token-2022 añade extensiones: comisiones automáticas en cada transferencia, un delegado permanente que puede mover tokens de cualquier cuenta, transferencias que solo se permiten a cuentas aprobadas, entre otras. Cuando un token usa Token-2022, conviene leer qué extensiones tiene activas.

La lección del Lab

Abajo tienes la lección «Permisos: emisión y congelación» del antiguo Lab, con dos fichas reales del 2026-10-16. Separa un permiso activo de una acusación y un permiso cerrado de una garantía.
