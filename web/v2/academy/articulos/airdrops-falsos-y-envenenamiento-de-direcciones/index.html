Airdrops falsos, envenenamiento de direcciones y tokens trampa

IntermedioActualizado 03-11-2026 2 min✓ Leído

RedesEthereumTronSolana

Aspectos clave

  • Un token que aparece sin pedirlo con una web para «reclamar» es casi siempre un cebo.
  • El envenenamiento de direcciones deja en tu historial una dirección parecida para que la copies por error.
  • Comprueba la dirección completa, no solo el principio y el final.
  • Un token trampa se puede comprar pero no vender; una venta simulada puede no bastar para descartarlo.

El regalo que no pediste

Un airdrop legítimo existe: proyectos que reparten tokens a ciertos usuarios. El falso imita esa idea. Aparece en tu wallet un token o un NFT con un nombre como «Recompensa: visita esta web». La web pide conectar la wallet y firmar para «reclamar». Lo que firmas entrega tus tokens, como en Firmar con cuidado en Solana, o concede un permiso, como en Permisos de contratos.

Qué hacer: no visites la web, no intentes venderlo y no interactúes con él. Muchas wallets permiten ocultarlo.

Una dirección casi igual

El envenenamiento de direcciones aprovecha una costumbre: copiar la dirección desde el historial.

  1. Envías fondos a la dirección de una amiga. Empieza por 7xQp y termina en 9fKe.
  2. Minutos después, recibes un envío de 0 o de una cantidad mínima desde otra dirección que también empieza por 7xQp y termina en 9fKe.
  3. La próxima vez, copias del historial la dirección de arriba, que es la del atacante.

Las direcciones de este ejemplo están recortadas a propósito: no son direcciones reales.

Cómo evitarlo:

  • Guarda las direcciones que usas en la libreta de la wallet y cópialas desde ahí.
  • Compara la dirección completa o, al menos, varios tramos del medio.
  • Para importes grandes, haz antes un envío pequeño y confirma con la otra persona.

El ataque se ve en todas las redes, sobre todo donde se mueven muchas monedas estables con comisiones bajas, como Tron o las redes EVM. En Ethereum y redes compatibles hay una variante: transferencias de cero unidades, o de un token falso con el mismo símbolo, que aparecen en tu historial sin que tú hayas hecho nada.

Tokens que no se pueden vender

Un token trampa deja comprar pero bloquea o grava las ventas. En redes EVM suele hacerse con código en el contrato del token. En Solana puede lograrse, por ejemplo, con una autoridad de congelación activa o con extensiones de Token-2022 como un gancho de transferencia o una comisión alta, explicadas en Tokens SPL y Token-2022.

Señales:

  • Hay muchas compras y casi ninguna venta de cuentas distintas del creador.
  • Alguien conserva autoridades que permiten cambiar las condiciones.
  • Una herramienta que simula la venta da error o una comisión muy alta.

Una simulación correcta hoy no garantiza que mañana siga igual si alguien puede cambiar las reglas.

La copia del token conocido

Igual que con las direcciones, hay suplantación de tokens: mismo nombre, mismo logotipo, distinto mint. Compruébalo siempre en la fuente oficial, como en Identificar un token.

Comprueba lo que has aprendido

En tu historial aparece un envío de 0 desde una dirección que empieza y termina igual que la de un contacto. ¿Qué haces?

Ver la respuesta

Correcta: No copiar direcciones del historial y usar la libreta guardada. Es el patrón del envenenamiento de direcciones.

  • Usarla, porque empieza y termina igual: El atacante genera direcciones que coinciden justo en esos tramos.
  • Responder con otro envío para comprobarla: Interactuar no aporta nada y puede confundirte más.

Practica

Clasifica cada situación inventada.

  • Un envío de 0 desde una dirección casi igual a la de un contactoBusca que la copies del historial.
  • Un NFT regalado que enlaza a una web para conectar la walletEs el mismo cebo con otro formato.
  • Un token con muchas compras y ventas que siempre fallanDeja comprar pero no vender.
  • Un token que aparece solo con el nombre «Visita esta web para reclamar»Lleva a una web que pide firmar.
