Lectura de la curvaCurve reading

Pega cualquier mint de Solana. La página detecta sola si la curva es de Pump.fun o de Raydium LaunchLab. Verás la plataforma, la moneda base y el estado de la curva tal como están en la cadena; en Raydium LaunchLab, también lo reunido, el objetivo de graduación, el progreso y, si migró, el pool de Raydium. Si no hay curva en ninguna de las dos, la página lo dice.Paste any Solana mint. The page detects on its own whether the curve is on Pump.fun or Raydium LaunchLab. You see the platform, the base currency, and the curve state as they are on chain; on Raydium LaunchLab, also the amount raised, the graduation target, the progress, and, if it migrated, the Raydium pool. If there is no curve on either, the page says so.

Lectura de datos públicos. No es una comparación de calidad, ni una recomendación, ni un aval. ORVUPI no tiene relación con estos tokens.Public data reading. It is not a quality comparison, a recommendation, or an endorsement. ORVUPI has no relationship with these tokens.

No es una auditoría ni una recomendación. Muestra datos públicos de la cadena en el momento indicado; no dice si un token es bueno, seguro o una buena compra.It is not an audit or a recommendation. It shows public chain data at the stated time; it does not say whether a token is good, safe, or a good purchase.

Escribir una dirección no avala ese token. No conecta carteras, no firma y no envía.Writing an address does not endorse that token. It does not connect a wallet, it does not sign, and it does not send.

Un emparejamiento no es una colaboración ni un respaldo.A pairing is not a collaboration or an endorsement.

La lectura usa primero https://solana-rpc.publicnode.com y https://api.mainnet-beta.solana.com. Si el primero no responde, prueba el siguiente. Esos servicios reciben la dirección y la IP según sus condiciones. Esta página no escribe el Cuaderno. El enlace de metadatos se muestra como texto y no se abre.The read uses https://solana-rpc.publicnode.com and https://api.mainnet-beta.solana.com, in that order. If the first one does not answer, it tries the next. Those services receive the address and the IP under their own terms. This page does not write the Notebook. The metadata link is shown as text and is not opened.
