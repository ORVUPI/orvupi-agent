기여하기

이 저장소에서 도구를 개선하는 데 도움이됩니다. 유용한 보고서는 다른 사람이 반복 할 수있는 버그입니다, 혼란 텍스트, 검토 할 수있는 번역, 또는 접근성 검사. Solana 토큰은 버그의 예일 수 있습니다.

주소는 토큰이 좋거나 안전하거나 승인되지 않습니다. 공식 ORVUPI 주소는 orvupi.com/token에 있습니다.

이것은 감사 또는 권고가 아닙니다.

자주 묻는 질문

  • 반복하는 단계와 버그.
  • 따르는 것은 어렵습니다.
  • 번역을 검토합니다.
  • 접근성 체크: 키보드, 큰 텍스트, 또는 화면 리더.

접수되지 않음

  • 구매 요청, 볼륨을 추가, 또는 승진.
  • 씨앗, 개인 키, 개인 이메일 또는 실제 이름.
  • 결제, 토큰, 보상, 또는 프로젝트의 공유에 대한 요청. 기여는 그 어떤 것에도 맞지 않습니다. 텍스트에 요청하면 공개 코멘트는 GitHub 사용자 이름만 인용할 수 있습니다.

그것을 보내는 방법

이 페이지에는 양식이 없습니다. ORVUPI 계정은 묻지 않습니다. GitHub는 자체 세션을 요청하여 발행 또는 제안을 열 수 있습니다. ORVUPI은 해당 세션을받지 않습니다. GitHub 양식을 로드하지 않으면 새 문제로 템플릿을 붙여넣으십시오.

문제 또는 변경 제안이 공개됩니다. 사용자 이름과 사용자 이름, GitHub에 동의하는 용어 및 개인 정보 보호 정책.

변경 제안을 보내면 저장소의 MIT 라이선스에 따라 게시된 것에 동의합니다. 이미지와 키트는 자체 라이센스가 제외됩니다. 이미지에 기여하는 경우, 그들이 가지고있는 라이센스를 말한다.

버그 신고 개선 제안 변경 제안 열기 템플릿 다운로드

다음을 포함하는 것

  • 버전: package.json 번호 또는 페이지의 날짜.
  • 단계, 예상된 결과, 그리고 관찰 된 결과.
  • Evidence: 오류 텍스트 또는 화면에 무엇인가. 키가 없습니다.
  • 토큰 주소는 버그를 반복해야만 합니다.

리뷰는 무엇인가요?

기록은 GitHub 문제입니다. 이 웹 사이트는 사본을 보관하지 않으며 리뷰 작성자를 할당하지 않습니다. 팀은 댓글에 국가를 작성:

  • 수신 : 문제가 열려 있으며 아직 댓글이 없습니다.
  • Pending: 코멘트는 검토되고 있습니다.
  • 허용 : 변경은 이미 저장소에 있습니다.
  • 중복 : 동일한 문제의 주석 점과이 하나는 닫힙니다.

마감일은 없습니다. 제출은 긴 또는 반복되기 때문에 허용되지 않습니다.

자주 묻는 질문 의 글 orvupi.hq@gmail.com 또는 읽기 보안 정책. 씨앗이나 열쇠를 보내지 마십시오. 보고서에는 지불이 없습니다.
