Crea con ORVUPI.Create with ORVUPI.

Elige una plantilla, escribe el nombre, el título y el cuerpo, selecciona fondo y pulpo o un logo propio, elige formato y descarga el PNG. Compartir abre el menú del sistema; no publica automáticamente.Choose a template, enter a name, title and body, select a background and octopus or your own logo, choose a format and download the PNG. Sharing opens the system menu; it does not post automatically.

Tus datos se quedan aquíYour data stays here

El logo se lee en este navegador y no se envía a un servidor. No se guarda con el borrador. El nombre ORVUPI activa nuestra mascota; otro nombre permite usar tu logo y no utiliza el pulpo. Los borradores anteriores se conservan.The logo is read in this browser and is not sent to a server. It is not saved with the draft. The ORVUPI name activates our mascot; another name lets you use your logo without the octopus. Previous drafts are preserved.
