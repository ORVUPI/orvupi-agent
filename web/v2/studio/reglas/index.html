Reglas y recursosRules and assets

Elige una plantilla, escribe el nombre o ticker (STUBX viene escrito), el título y el cuerpo, elige una imagen de fondo y un avatar de STUBX o el logo de tu token, elige el formato y descarga el PNG. Compartir abre el menú del sistema y no publica nada.Pick a template, write the name or ticker (STUBX is already filled in), the title and the body, pick a background image and a STUBX avatar or your token’s logo, pick the format, and download the PNG. Share opens the system menu and does not post anything.

No escribas precios, promesas de subida, urgencia, regalos, llamadas a comprar ni nada que parezca un canal oficial. No pongas direcciones, enlaces ni nombres de cuenta. El nombre del token pasa por el mismo filtro que el título y el cuerpo. Si el filtro avisa, la descarga queda parada hasta que cambies el texto.Do not write prices, promises of a rise, urgency, gifts, calls to buy, or anything that looks like an official channel. Do not put addresses, links, or account names. The token name goes through the same filter as the title and the body. If the filter warns you, the download stays stopped until you change the text.

El filtro ayuda, pero no es una garantía. La imagen sigue siendo contenido no oficial.The filter helps, but it is not a guarantee. The image remains unofficial content.

No hay galería pública. El logo que eliges se lee en este navegador y no se envía a ningún servidor. No se guarda con el borrador. La imagen se crea en este dispositivo. El logo puede ser JPG, PNG o WebP; si pasa de 2048 px, se reduce. Los recursos de STUBX siguen como opción por defecto. Si el nombre no es STUBX, la mascota no se usa y no se puede elegir.There is no public gallery. The logo you choose is read in this browser and is not sent to any server. It is not saved with the draft. The image is created on this device. The logo can be JPG, PNG or WebP; if it is over 2048 px, it is reduced. STUBX assets stay the default option. If the name is not STUBX, the mascot is not used and cannot be chosen.
