# Hoja de ruta

El orden sigue el manual. Una fase no se marca hecha hasta que el ciclo real pasa las pruebas.

| Fase | Estado en 0.2.0 | Contenido |
| --- | --- | --- |
| 0 Investigación | Hecha | Este registro, `LICENSE_REVIEW.md` y `docs/PARIDAD_DRIVE.md` |
| 1 Core | Hecha en alfa | App, navegación, design system, almacenamiento, ajustes, PWA, copia |
| 2 Docs | Hecha en alfa, ampliada | Crear, editar, guardar, cerrar, recuperar, exportar, estilos, comentarios e historial manual |
| 3 Files | Hecha en local, con límites | Carpetas, mover, papelera, destacados, filtros, lista o cuadrícula, etiquetas y vista previa |
| 4 PDF | No empezada como visor | Un PDF importado se guarda, se previsualiza como descarga y se descarga. No hay visor |
| 5 Sheets | Básica | Motor propio, CSV y XLSX sencillo. Sin HyperFormula ni Handsontable |
| 6 AI | Preparada, sin modelo | `NoModelProvider` y detección de equipo |
| 7 Templates | Once arranques en Docs | No es la biblioteca de la fase 7 |
| 8 Slides | Básica | Título, texto y presentación local. Sin temas ni PPTX |
| 9 Integración con IA | Bloqueada por la fase 6 | |
| 10 Automatizaciones | No empezada | |

La versión 1 del manual, con visor PDF, cuadrícula grande y modelo local, queda fuera de esta alfa. No se publica esta build como estable.
