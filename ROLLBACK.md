# Volver atrás el Cuaderno

Esta nota copia el plan que está en CHANGELOG.md, entrada del 2026-10-11. No despliega la web.

La base local del Cuaderno pasa a la versión 2. El navegador no abre una versión menor: la página que hoy está en stubxai.com abre la versión 1. Si esta entrega se publica y luego se vuelve a esa página anterior, el Cuaderno de ese navegador no abre. Para volver atrás: cargar otra vez esta página, o borrar en el navegador los datos del sitio de la base llamada stubx-cuaderno. Esas fichas solo están en ese navegador; borrarlas las quita de ahí y no las envía a ningún servidor. Si este código encuentra una versión mayor, abre la base sin subirla y sigue.

## English

The Notebook’s local database moves to version 2. A browser will not open a lower version: the page on stubxai.com today opens version 1. If this change is published and that older page is put back, the Notebook in that browser does not open. To go back: load this page again, or delete in the browser the site data for the database named stubx-cuaderno. Those cards exist only in that browser; deleting them removes them there and does not send them to any server. If this code finds a higher version, it opens the database without upgrading it and keeps going.
