## Estado del token

A fecha de esta guía no se ha publicado en este repositorio una dirección verificada de token ORVUPI. La elección de una plataforma o la preparación de un formulario no demuestran que se haya creado.

La dirección histórica `TNWwnzecb37272ZoySDE6D2UcmqNnU12EqtycNSpump` corresponde al token anterior STUBX. **Nunca debe presentarse como dirección de ORVUPI.** Su conservación no implica equivalencia, conversión, reparto ni migración automática. Cualquier decisión futura sobre titulares anteriores debe explicarse antes de ejecutarse.

El registro `verify/registry/canonical.json`, `state/public-mint.json`, las fichas de `verify/examples/`, los metadatos on-chain y sus direcciones conservan su significado original. No se cambia el nombre de esos datos para aparentar un token nuevo. La presencia de lecturas de Pump.fun es una capacidad histórica de consulta, no una decisión de lanzar ORVUPI allí.

## Herramientas y compatibilidad

Se conservan Verify, Lab, Aprender, Cuaderno, Studio, Comparar, Pares y Tablero. La web y la CLI no son la misma superficie: la CLI y los borradores aún pueden mostrar textos heredados. Esta entrega documental no afirma que todo el código haya cambiado de marca.

Se mantienen por compatibilidad:

- Paquete `@stubx/agents`, esquemas `stubx.ppm/v0` e identificador de política `stubx-agent-limits`.
- Actores `stubx-agent`, cabeceras de anclas, formatos de hashes y evidencias de Actions.
- Claves de progreso `stubx-lab-*`, base local `stubx-cuaderno` y variables técnicas como `STUBX_PUBLISH` y `STUBX_NAME_DENYLIST`.
- Direcciones, fixtures, metadatos, pruebas de procedencia, licencias y avisos de autoría anteriores.

Cambiar estos identificadores requiere una migración coordinada y comprobaciones de compatibilidad. No se hace mediante una sustitución global de nombres.
